# 00 · 范围（v1.0）

状态：P0 冻结 · 2026-10-10

## 产品形态

两个独立的 iPhone App，来自同一个仓库：

| App | 运行设备 | 联网 | 持有私钥 | 职责 |
|---|---|---|---|---|
| **Signer**（签名机） | 专用 iPhone，激活后永不联网 | 否 | 是（默认不落盘） | 生成/导入种子、导出公钥、解析待签交易、完整显示、签名 |
| **Watcher**（观察机） | 任意 iPhone | 是 | 否，只有公钥 | 查余额、构造未签名交易、展示二维码、扫回签名、广播 |

两机之间**只**通过屏幕二维码 + 摄像头传数据（动画二维码，UR 编码）。

## 支持的链（v1.0）

| 链 | 曲线 | 派生路径 | 说明 |
|---|---|---|---|
| BTC | secp256k1（ECDSA + Schnorr） | BIP84 `m/84'/0'/0'`、BIP86 `m/86'/0'/0'` | PSBT；兼容 Sparrow |
| DOGE | secp256k1 | BIP44 `m/44'/3'/0'` | 旧式交易（无隔离见证），签名机必须拿到前序交易核对金额 |
| ETH / BNB Chain / 其他 EVM | secp256k1 + Keccak-256 | `m/44'/60'/0'/0/i` | EIP-155 / EIP-1559 / EIP-712；兼容 ERC-4527 |
| SOL | ed25519 | SLIP-10 `m/44'/501'/i'/0'`（Phantom / Solflare / Trezor）；另支持 Ledger Live 的 `m/44'/501'/i'` 与 `m/44'/501'`（D34） | legacy 与 v0 消息 |
| NEAR | ed25519 | SLIP-10 `m/44'/397'/0'` | borsh 序列化 |
| TRON | secp256k1 + Keccak-256 | `m/44'/195'/0'/0/i` | protobuf；USDT-TRC20 |

v2 候选（不在 v1 范围）：LTC、BCH（复用 UTXO 模块，成本低）；TON、SUI、APT、XRP（每条都是新解析器和新审计范围）。

## 功能清单（v1.0）

- 种子：生成（系统随机数 + 可选骰子熵）、导入（手输 / SeedQR）、BIP39 passphrase（永不保存）
- 种子保存：**无状态（默认）**；可选"存储模式"（Secure Enclave P-256 加密后存钥匙串，仅本机）
- 导出公钥：各链 xpub / 公钥 / 地址，二维码给观察机
- 签名：上述 6 类链的转账与常见合约交互；每条链的"危险操作"默认拒签（见威胁模型）
- 地址：完整分组显示、白名单、相似地址告警
- 观察机：余额、历史、构造交易、广播；自建节点优先，否则多 RPC 交叉核对

## 明确不做（Non-goals）

- 不做盲签开关
- 不做浏览器 / DApp 内嵌、不做 WalletConnect（v1）
- 不做云备份、不做遥测、不做崩溃上报
- 不使用任何以预编译二进制分发的依赖
- 不使用 Flutter / React Native / CocoaPods / 任何 SPM 第三方包
- 不上 App Store（v1 只支持"自己从源码编译安装"）
