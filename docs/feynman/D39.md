# D39 费曼汇报：签名机记住钱包，用 6 位密码开门

日期：2026-10-11 · 状态：代码完成，模拟器界面流程已验证；安全复审与真机验证未做（见交接文档 `docs/handoff/2026-10-11-d39-pin-vault-handoff.md`）

## 1. 一句话

签名机现在可以把钱包加密存在本机，以后打开只要输 6 位密码；密码错一次，存的钱包就被清除。

## 2. 讲给外行听

以前签名机像一个"每次都要重新背一遍口令"的保险箱：每次打开都要把 12 或 24 个单词一个个输进去，很安全，但太累。

现在像给保险箱配了一把"一次性密码锁"：
- 钱包被锁在一个只属于这台手机的芯片（Secure Enclave）配合 6 位密码才能打开的盒子里；
- 打开 App、或者从后台切回来，都要输密码；
- 密码错一次，盒子直接销毁，只能拿抄在纸上的助记词重新恢复——所以纸上的助记词一定要抄好；
- 不想存也可以，点"不保存"就回到原来的用法。

## 3. 具体做了什么

| 产出物 | 位置 | 说明 |
|---|---|---|
| 加密保存 | `ios/Signer/Signer/WalletVault.swift` | Secure Enclave 密钥 + ECDH + HKDF(盐, PIN) + AES-GCM；输错即清除 |
| 密码界面 | `ios/Signer/Signer/PinViews.swift` | 自带数字键盘、设置密码（输两次）、解锁、忘记密码 |
| 状态机 | `ios/Signer/Signer/RootView.swift` | 启动有保存就要 PIN；切后台就锁；passphrase 没保存时再问 |
| 白名单 | `tools/checks/signer-imports.allow`、`signer-libs.allow` | 新符号逐项审查后加入 |
| 文档 | D39（中英）、T14、范围、设备准备、进度图 | |

## 4. 怎么证明它是对的

- `tools/ios/build-signer.sh sim` 与 `device`：都以"全部检查通过（含产物）"结束。
- 模拟器：设置密码页、两次输入、保存失败提示、"不保存"进入钱包、切到后台再回来会话已丢弃，都已看到。
- **未验证**：真机上的保存、解锁、输错清除（模拟器没有 Secure Enclave）。**未完成**：独立安全复审。
