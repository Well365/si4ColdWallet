# 04 · 签名机设备准备流程

状态：P0 草案 · 2026-10-10 · P1 实测后修订

> 顺序不能乱。**第 6 步之前，手机上不得出现任何种子。**

## 需要准备

- 1 台专用 iPhone（仍在 iOS 更新支持范围内的机型）
- 1 台构建用 Mac（已安装 Xcode，见 `toolchain/TOOLCHAIN.lock`）
- Apple 付费开发者账号（开发证书 1 年有效；免费账号 7 天过期，不适用）
- 数据线（原装或 MFi 认证）

## 步骤

1. **抹掉手机**：设置 → 通用 → 传输或还原 iPhone → 抹掉所有内容和设置。
2. **激活**（此步必须联网，无法避免）：
   - 不登录 Apple ID（选"忘记密码或没有 Apple ID？" → "以后在设置中设置"）
   - 关闭：定位服务、Siri、屏幕使用时间、分析与改进、iCloud
   - 设置 6 位以上设备密码（签名机"本机保存钱包"必须有设备密码：没有就无法保存；取消设备密码时系统会删除保存的钱包，见 D39）
3. **注册设备**：Mac 上 Xcode → Window → Devices and Simulators 连接手机，把设备加入开发者账号。
4. **开发者模式**：手机 设置 → 隐私与安全性 → 开发者模式 → 开启 → 重启 → 输入密码确认。
5. **安装并信任**（此时手机仍联网）：
   - Mac 上从源码构建 Signer 并用数据线安装（见 `ios/Signer/README.md`）
   - 若提示"未受信任的开发者"：设置 → 通用 → VPN 与设备管理 → 信任
   - 打开 Signer 一次，确认能启动
6. **永久断网**：
   - 取出 SIM 卡 / 删除 eSIM
   - 设置 → 无线局域网 → 关；设置 → 蓝牙 → 关（控制中心里关不彻底）
   - 开启飞行模式，并确认飞行模式下 WiFi、蓝牙仍为关闭
   - 设置 → 通用 → 隔空投送 → 接收关闭
   - 可选：开启锁定模式（P1 验证与 Signer 的兼容性）
7. **之后才**在 Signer 中生成或导入种子。

## 之后的纪律

- 永不连接任何 WiFi、永不插 SIM、永不连接电脑（升级 Signer 除外，升级时也不联网）
- 不用时关机，放在屏蔽袋中
- 升级 Signer：Mac 断网构建 → 数据线安装 → 在 Signer 内核对版本哈希

## P1 必须实测的问题

| 编号 | 问题 | 方法 | 通过标准 |
|---|---|---|---|
| D1 | 开发者证书信任后，断网能否长期启动 | 按上述流程设置后断网，第 1、7、30、60、90 天各启动一次 | 全部能启动 |
| D2 | 重启后断网能否启动 | 断网状态下关机重启后打开 Signer | 能启动 |
| D3 | 锁定模式是否影响开发者签名 App | 开启锁定模式后启动 | 能启动 |
| D4 | 断网状态下用数据线升级 Signer 是否可行 | Mac 断网，Xcode 安装新版本 | 能安装并启动 |

如果 D1 或 D2 不通过：进入方案评审（备选：改为 App Store/TestFlight 分发并放弃可验证性；或签名机改用专用硬件）。
